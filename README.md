# Proyecto-Facturas
Primer Proyecto de Programacion I

A travez de este proyecto se busca interpretar un tema de la vida real en este caso las facturas que son generadas por compras o ventas de productos y como estas pueden ser convertidad en objetos programables para intereses especificos

la cuestion aqui tambien incluye el uso de menu CRUD especial para la gestion de datos, clases abstractas como control obligatorio de implementacion, clases genericas para las que lo requieran y relaciones de herencia y demas temas relacionados
